INTÉGRATION AU SITE

1. Exporter le clip sans texte. Les titres et les boutons restent en HTML pour conserver leur netteté et la traduction français / anglais.
2. Placer le fichier sous dist/assets/header-vortex.mp4 dans le projet.
3. Dans dist/app.js, remplacer :
   const HERO_VIDEO_URL = 'assets/header-mavrik-scroll.mp4';
   par :
   const HERO_VIDEO_URL = 'assets/header-vortex.mp4';
4. Republier le site. La progression du défilement pilote déjà le temps de la vidéo dans les deux sens. L’image reste visible jusqu’au chargement de la vidéo.

Une première vidéo a été générée avec MiniMax Hailuo 2.3 Fast et intégrée sous assets/header-mavrik-scroll.mp4. Le header reste fixé pendant le défilement et la vidéo avance ou recule selon le sens du scroll. Le prompt ci-dessus reste disponible pour une nouvelle prise éventuelle.

Pour une lecture arrière plus fluide, un MP4 comportant des images clés fréquentes est préférable. Option de réencodage si FFmpeg est disponible :
ffmpeg -i animation-higgsfield.mp4 -an -c:v libx264 -crf 20 -preset medium -pix_fmt yuv420p -g 12 -keyint_min 12 -sc_threshold 0 -movflags +faststart header-vortex.mp4

Après intégration, vérifier la fluidité sur téléphone. Le mode de réduction des animations du navigateur est respecté par le site.
